Title: Introduction to AI and ML, Tian + Ishaq, MIT Spokes 2025.
- AI = branch of CS making machines intelligent; ML = learning from data without explicit instructions. Analogies: AI is education / ML is school; AI is light / ML is sun; AI is writing / ML is pencil.
- How a machine learns: Data -> Algorithm -> Decisions. Example: dog or cat?
- Activity 1: accuracy of a "SPOKES classroom AI" - students (the algorithm) classify new images as category A or B; discuss accuracy, strategies, challenges.
- Activity 2: Train a machine with a SPOKES classroom: categories happy/sad faces drawn by students; upload to https://machinelearningforkids.co.uk/ ; test; discuss.
- Activity 3: Training an unsupervised model (students as model sorting images by patterns).
- Activity 4: Training a "human robot" with punishment/reward numbers.
- Major ML applications: speech, images, robots/self-driving cars, recommendation systems.
- Lesson: more examples -> smarter machine.
