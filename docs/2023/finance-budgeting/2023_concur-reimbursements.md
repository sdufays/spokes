# Concur reimbursements guide (last updated June 9, 2023)
- **Learning supplies:** atlas.mit.edu -> reimbursements / submit RFP; send to Marvelin (Edgerton; email in Outlook).
- **Travel-related / everything else:** Concur.
- Use Concur for anything paid out of pocket (should only be stuff before the travel card arrived). Andrew uploads travel-card receipts from the "Travel card receipts" Drive folder (report type may differ since it need not be reimbursed).

Steps:
1. Sign in via Touchstone at https://concur.mit.edu
2. Expense -> create new report. Fields: Report Name: something Spokes-related; Trip Purpose: **Field Trip**; Cost Object: **2530032 SPOKES**; Trip Start 06/04/2023; Trip End 08/16/2023; Destination: California; Classification: Domestic; Benefit of the Project: **Non Sponsored Activity**.
3. Add each item with all mandatory fields + receipt. Save report.
- Make sure **direct deposit is set up in atlas.mit.edu** or they mail a check.
- **Submit after 8/16** (end of trip), then wait for money.
