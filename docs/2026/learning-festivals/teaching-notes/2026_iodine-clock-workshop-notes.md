# Iodine Clock Workshop Notes (2026)

## Outline
1. Introduction: introduce ourselves and Spokes (major, career aspirations); have students introduce themselves. Motivate with why reaction rates matter: metabolism/enzymes, batteries, medicine absorption, cooking (baking bread, caramelizing sugar).
2. The Science
   - Balancing reactions / law of conservation of mass (same number of each element on each side).
   - I2 + vitamin C -> 2 I- + oxidized vitamin C (fast). Vitamin C is the inhibitor.
   - H2O2 + 2 I- -> I2 (slower). H2O2 is the oxidizer that drives the reaction.
   - I2 + starch -> blue-black I2-starch complex.
3. Demo (procedure adapted from Cox Science Center and Aquarium)
   - Crush one 1000 mg vitamin C tablet, dissolve in 2 oz distilled water ("Vitamin C sol.").
   - Solution A: 1 tsp iodine tincture + 1 tsp vitamin C solution + 2 oz water.
   - Solution B: 2 oz water + 3 tsp 3% hydrogen peroxide + 1/2 tsp liquid starch.
   - Pour A into B, start timer, stir, observe.
4. Students' turn: same procedure but vary amount of vitamin C; assign a different group to each amount.
5. Conclusion: what trends? Create 3 plots: vitamin C vs time (zero order), ln(conc) vs time (first order), 1/conc vs time (second order); the linear one gives the reaction order. Takeaways and questions.

## Future ideas (difficulty levels)
- Single permanent color change (current).
- Clock/oscillation reaction (Belousov-Zhabotinsky) - chemical oscillators.
- Introduce spectator ions.

## Group-work script (logistics)
1. Everyone puts on PPE.
2. Set out big bottles for solutions A and B x8; pass out cups for DS (distilled) water x4.
3. Each group adds 12 mL DS water per A and B bottle (x2 per group).
4. Say "working on only solution B": walk around with beakers of H2O2 and liquid starch.
5. Say "working on only solution A": pass out vitamin C water to each group, add to A; walk around adding iodine.
6. Keep A and B separate until everyone is ready, then all groups pour at once and start timers.
