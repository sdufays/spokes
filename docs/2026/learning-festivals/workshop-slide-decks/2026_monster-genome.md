# MIT Spokes Workshop 2026: Monster Genomes (slide content)
Flow: What determines what we look like? -> traits of monster parents (skin color, eye size, horn, nose shape) -> each trait (gene) has two versions (alleles), one copy from each parent -> dominant alleles win with one copy (notation: blue S dominant, red s recessive; SS/Ss/ss) -> phenotype vs genotype -> Punnett squares (SS x ss = all Ss; Ss x Ss = 3:1; Ss x ss = 50/50) -> table of Ma/Pa genotypes (Skin ss/SS, Eye Ee/ee, Horn Hh/Hh, Nose NN/Nn) -> students work out the child genotype per trait -> practice questions on which allele wins -> "Now let's BUILD" the monster with craft supplies (skin color co-dominant; eye color, horn recessive/dominant combos; nose) -> worksheet (mom genotype, dad genotype, child genotype, child phenotype) -> DEBRIEF: why did everybody's monster look different with the same parents? What simplifications does the model make vs human genetics?
