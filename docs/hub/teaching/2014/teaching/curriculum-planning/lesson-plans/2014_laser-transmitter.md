Laser Transmitter

Technical Objectives:

Teach them basic concepts about analog signals, EM radiation, and circuits.

Have them understand and build a circuit that takes a signal and transmits it via laser. In longer sessions the students will also build a receiver.

Talk about why this isn’t practical, how it could be modified to make it practical.
