### Notes carried over from the first pass
People along the route who said "I wish you could teach in my town": Matt's wife in Carbondale, Illinois (last stop in Illinois); the "steampunk pastor" from Steamboat Springs; Colby, Kansas sheriff.
- Many reasons to do outreach. Team felt the most impact was on middle-school / early high-school kids, but received many elementary kids who demand more energy. Hard to actually attract older kids even though everyone was told to aim for MS/HS.
- Preparation: Maile and Erin handled LF communication at first, then Evan and Edgardo. Some coordinators were bad at email; in hindsight Evan should have called them. A status-tracking spreadsheet was essential because each LF differed (times, ages, space).
- Class preparation was done very late: funding struggles lasted into April and in May people were too busy to prepare classes.
- Practical: ask hosts up front whether lunch is provided; ask for room count/floorplan; aim for socials after last workshop.

|  |  |  |  |  | LF reflections: |  |  |  |  |  |  |  |
|  |  |  |  |  | There are many different reasons to do outreach / many different ways to make an impact. I think our learning festivals covered a wide array of these reasons and also gave us some pretty good experience (particularly for people with less education experience). I think for our trip, middle-school / early high school is where I feel like we made the most impact, but I think we got a large amount of elementary school kids (who are unfortunately usually the ones that require lots of attention/energy). I don't know if there's any way to actually get older kids (we told everyone to try and get MS/HS kids), but if I were to do it again, I'd try for that. I think we overall weren't fans of the Farmington/St Louis LFs and I think lots of team members werent' fans of the Kansas City LF. I think one thing we agreed on was that we had lots of LFs that were very clustered at the beginning / end meaning the middle had lots of dry spells where there was lots of biking. I think there were also lots of places we stopped that fit our target demographic of not having access to this kind of opportunity otherwise (unlike Farmington or Lindon) where it woud've made sense to teach (basically any of the smaller towns in Kansas or Colorado or Utah).  On the other hand, continuity is important to make a lasting impact in a community. I think Hazard, KY is town that really shows how a strong connection can really mean a lot to a community. |  |  |  |  |  |  |  |
