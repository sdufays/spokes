- Blog: everyone can create accounts and be site admins to write posts.
- Billing: Evan fronted the cost. "Unlimited" Premium plan = $168/year. Domain mitspokes.com expires each April; renewal $14.95/year.
- Apps: Inffuse Testimonials (4 free; unlimited $3.99/mo; may be useful for fundraising); Email Marketing Essentials (3 emails/mo free, 5/mo ~$10; in 2018 blog posts were emailed to ~100 people).
- Archive: 2018 site at mitspokes.wixsite.com/2018 (now free-hosted); change main mitspokes site and link to the 2018 site once new site is done.
