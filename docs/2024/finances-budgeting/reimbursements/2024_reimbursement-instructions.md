---
1. Create a folder with the date of purchase if it does not exist (e.g., 3/07/24).
2. Add a picture/PDF/screenshot of the receipt. Make sure it is clear.
3. Give the receipt a descriptive file name.

Folder layout in 2024: Reimbursements/{3/7/24, 3/21/24, 3/27/24, 6/1/24, 6/2/24, 6/3/24}; 3 of the 6/x folders were empty; the 3/x folders hold campsite reservation confirmations (see 2024_campsite-reservations).
