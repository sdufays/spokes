**Ideas:** intro to what coding is with real-world examples; Python or Scratch depending on kids' age; Hello World, name echo, Mad Libs, choose-your-own-adventure, math functions, riddle/joke/game; careers in coding; continue learning (handouts, Scratch link to show parents).
**Materials:** computers with Python loaded, Mad Libs book.
**Open questions:** laptop internet/capabilities; charging all laptops (power strips, ask other team); getting Scratch/Python on laptops; printing handouts.
**Resources:** scratch.mit.edu/tips; Getting Started Guide (PDF); example 3-hour workshop at coweb.cc.gatech.edu/ice-gt/1258; tutorials: getStarted, music, racegame.
**5/9 meeting notes:** pictures help (projector or printed pictures); slides/pics from workshop in Chile; show CS applies to any interest (security, rockets, science); give freedom to pick tutorials; saving projects via a group account; paper handout.
