# Iodine Clock notes (2026) - instructor talking points

1. Warm-up: what comes to mind when you think chemistry? Everyday chemical reactions (rust, baking, digestion). Definition: substances turn into NEW substances with different properties (not just mixing). Signs: color change, gas/bubbles, temperature change, precipitate. Today: color change and gas-producing reaction.
2. Conservation of mass: matter neither created nor destroyed; same number of each element on both sides.
3. Reaction rate = change in concentration / time. Factors: temperature (more energetic collisions), catalysts (lower activation energy, not consumed), surface area, concentration (crowded particles collide more).
4. Iodine clock equations. Ask: what does vitamin C do in our bodies?
5. EXPERIMENT.
6. Debrief "why did the color change": iodine (I2, brownish red) is destroyed to iodide (clear) by vitamin C very fast (rxn 1); H2O2 keeps converting I- back to I2 (rxn 2); when vitamin C runs out, I2 accumulates and binds starch (rxn 3) -> blue-black. Two competing "racing" reactions. After the color change rxn 2 keeps going; it is just no longer masked.
7. Predict: add more vitamin C -> delays color change; add more H2O2 -> may never turn blue.
8. Limiting reagent: vitamin C here. It depends on the starting ratio, NOT an intrinsic property. Read the balanced equation (e.g., CH4 + 2 O2: with 1 part CH4 and 1 part O2, O2 limits; with 4 parts O2, CH4 limits). Numbers come from conservation of mass.
9. Mini redox lesson: reduction = gaining electrons, oxidation = losing; always co-occur (REDOX). Iodine is reduced, vitamin C oxidized. Vitamin C is an antioxidant: it donates electrons fast to reactive molecules before they damage DNA/proteins/starch-like biomolecules.
10. Starch: long glucose chain curled into a helix; bystander that turns blue when I2 slots in. More starch = darker blue, no effect on rate.
11. Plot times from the reaction: increasing vitamin C concentration -> longer time to completion.
