# Iodine Clock Reaction slides (The Chemistry of Reaction Kinetics)
- Goal: understand speed of chemical reactions; solution turns dark blue when reaction completes; time it to find the rate. Why: medicine absorption, metabolism, batteries, cooking.
- Law of conservation of mass; combustion/decomposition examples (2NH3 -> N2 + 3H2).
- Rate of reaction = speed at which reactant concentration decreases and product increases.
- Reactions: vitamin C reduces iodine (brownish red) to iodide (clear), fast; H2O2 converts iodide back to iodine; iodine + starch = dark blue; vitamin C slows overall reaction.
- Procedure: Solution A = 12 mL DS water + 1 mL vitamin C solution + 2 mL iodine. Solution B = 12 mL DS water + 3 mL 3% H2O2 + 0.5 mL liquid starch.
- Characteristics: vitamin C = inhibitor (reacts fastest), H2O2 = oxidizer (drives reaction, slow), starch = color indicator.
- Group work (1000 mg vitamin C tablet each): Group 1: 60 mL DS water (0.0167 g/mL); Group 2: 40 mL (0.025 g/mL); Group 3: 30 mL (0.033 g/mL); Group 4: 25 mL (0.04 g/mL).
- Graph concentration vs time; Questions.
