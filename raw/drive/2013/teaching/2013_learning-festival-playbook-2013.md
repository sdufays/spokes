## Class rules and order of events
Introduce Spokes/team first (build investment), then rules; breakdown of day; release to rooms; **have teachers repeat rules in classrooms**; give expectations before every new activity. Three activity types: mini-lecture (no notes), discussion/workshop. Rules framed as "How to have fun with Spokes" in a comedy routine with skits (spokesmen model bad behavior): follow the speaker; raise hand; move/talk only about Spokes; no notes/homework. Consequences: first disruption = warning, second = sent to a designated room (ask schools for a spare room). Advice from TFA's Joshua: be direct and clear; "think about talking downhill"; behavior rarely a problem. Observe others' classes first days; discuss improvements after Sacramento.
## Logistics
Offer 3 classes in parallel (6 total), 10-30 per class; need 3 classrooms + computer lab (10-20 computers, projector); each class has a backup teacher; end-of-class student reflections; short video interviews (with parental consent); **mandatory parent consent: "every student's parents must sign the attached form; print and distribute one week in advance"**; Photo/Video release form template (Spokes America; parents sign; opt-out by not returning or emailing spokes@mit.edu). Class size by teacher in 6/2013: Kaitlyn 16, Titiaan 15, Claire 20, Phillip 10, Jeff 20.

## Lessons from July-August 2013 meetings
- Project/"Pursuing your passion" class **did not land**: few students into it; redesign so classes themselves become the project; build whole-day single-topic tracks; present an edX class at the end of yours (7/10, 7/25).
- **Decision 7/25 (Kansas City): core focus after summer = Exposure (great learning in varied arenas) rather than Guidance (mentoring).**
- Younger-than-7th graders: Kaitlyn wanted a floor; mixed MS/HS audiences are hard; 100 kids at CO Springs (same group all day) -- bring a bike in as intro; random numbers from a hat for class choice.
- St. Louis: 2-hour workshops each, 1.5 h after brainstorm for action steps/websites; wall of sticky-note ideas; schedule 1:00 intro ... 5:40 done; 3 rooms (living room, basement, barn).
- Aug 14 school (kids held back/treated like friends of teachers): 45 students, 3 rooms, 16 computers + 9 of ours; **shorter classes + longer projects**; demos at end filmed; interviews on day one.
- Ask schools for explicit info needs; request $500 if they can; Titiaan budgeted $30 per location class supplies, Turner $350.
## Project Box idea (July 2013 Emporia/KC meetings)
Monthly $30 hands-on project subscription box for ages 12-14 (renewable energy, 3D-scanner turntable $45, neuro, telescope, build-a-computer); goals excitement/exposure/engineering; contents secret until shipped then published; competitors: ExplorabBox, Whimsey Box, Amazepack, XploreBox, Howtoons, Magic School Bus Science Club. Never launched.
