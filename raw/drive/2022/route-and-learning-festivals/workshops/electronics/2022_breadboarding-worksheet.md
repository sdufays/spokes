Let’s Learn About Breadboarding!

1. Find the Circuit. In order to create a working circuit, there must be a closed loop. Wires (shown in black) were added to this breadboard to create four closed loops. 

Using a pencil, draw a line starting from the red terminal and ending at the blue terminal that connects all the wires together to indicate the closed loop.

2. Close the circuit. The following set of wires form open loops, meaning that electricity can not flow through them. We need to fix this! Using a pencil, add wire(s) in order to form a closed loop.

3. Building Circuits. A simple LED circuit contains a battery, resistor, LED and wires. A diagram of this circuit is shown below.

This LED circuit can be built on the breadboard as shown below. Remember that LEDs have a positive end (longer) and negative end (shorter end). 

4. Adding a Button. To create a more interesting circuit try adding a button! The diagram is shown below. See if you can figure out how to make this on a breadboard. 

5. More LEDs. So far we’ve been adding everything in series. Now let’s try adding another LED in parallel with the first LED.

6. Let’s Make Some Noise! A buzzer is another electrical component that we can add to our circuit! It is used to make noise. Can you try to add a buzzer without the help of a circuit diagram?

7. Challenge. Let’s add a potentiometer. The potentiometer acts as a dial that allows us to control the amount of electricity flowing through the circuit.
