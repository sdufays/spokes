Spokes Hub Publicity Outline:

One “Official” NAME, USERNAME, MAILING LIST, and PASSWORD(s) should be chosen for all of Spokes, whether it be “Spokes”, “Spokes America”, “Spokes Hub”, or something entirely different.

All accounts and passwords should be logged to Social Media Spreadsheet

TARGET AUDIENCES - All Social Media Outlets should be appropriate for Sponsors, Parents, Students, and Teachers.

Website
There should be one overall Spokes America Hub website that links to each of the individual Spokes pages (MIT/Harvard, Stanford, Tanzania, etc.) This website medium should be easily adaptable to all students (not just computer science majors) therefore, some bootstrapped website (such as Wix, Squarespace, etc.) might be a better platform

Facebook
Similarly, there should be an overall Spokes America facebook group and each school can have their own page.

Blog
Spokes Hub should consolidate to use one platform for blogs. There should be one large blog page with a separation such as #MIT/Harvard Spokes #Stanford Spokes. We think that the blog should be combined with the website. This should help with maintaining the frequency of blog posts. Additionally, this would give past members a platform to continue posting.

Instagram
There should be one large Spokes America Hub Instagram where all pictures are posted. Again hashtags can be used to separate between groups

Twitter

Youtube
There should be one large youtube user. Different playlists can be made for different groups/years

Fundraising/Crowdfund
***MIT/Harvard: Currently under MIT, the only way to fundraise is through MIT Crowdfund which must be remade each year***
If separate from MIT/Edgerton, there should be one platform (such as Indiegogo) used for all fundraising for Spokes Hub. Underneath this umbrella, there can be individual fundraisers for each group (for things such as personal donations from family members)

Warmshowers - targeted at hosts
Warmshowers should consolidate into one account - The Spokes 2017 Warmshowers has been changed to “Spokes America”. This preserves reviews from hosts and past ratings.

Amazon
Current system has MIT students making a new mailing list and a new amazon account every year to take advantage of free Amazon Prime. This can continue for the short-term (1-5 years), but non-profits can possibly get Amazon Prime/other Amazon benefits? If not, Spokes Hub can possibly pay yearly for membership.

Email Newsletter
Currently DO NOT have one. One global newsletter would be easiest to handle - All Spokes teams can have access to newsletter and send out periodic update emails from there.

LinkedIn
Currently DO NOT have one. We should create one once we are established as a non-profit.

Pictures/Gallery
Public: There should be a clean, crisp way to post public pictures to website (similar to Stanford’s website currently)
Private: All pictures should be posted to one platform. Run into problems with dropbox, google drive, etc. with amount of storage and how messy it gets. Could look for better options to post all pictures and make it easy to choose pictures for publicity
