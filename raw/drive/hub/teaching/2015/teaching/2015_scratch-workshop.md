Prior knowledge

Computer graphics (e.g. Paint)
Simple math
Addition, subtraction
Coordinate graph
Angles (degrees)
Established Goals
Students will be able to...
Model things in the real world using procedural code
1) Can think procedurally
2) Can formalize that thinking through mouth and paper
3) Can translate procedure to the computer
Create things that are not possible in the real world
Can think creatively about what new things are possible virtually
Design a project and execute it
1) Can come up with an idea
2) Can develop a plan for what is needed to complete it (or know where they can go to find what is needed)
3) Can incorporate new ideas along the way
