1. An intro to processing
A programming language
Designed to make visuals
Locally on your computer or on the internet and can share them easily
Later today you can take a look at some of the programs others have created and see what's possible
2. Tutorial walk through: http://sketchpad.cc/TID4GK6elK (http://is.gd/spokesamerica)
We're going to dive right in.
Fundamentally, there are two functions you need to define, setup and draw
What is a function?
The function of a car is to move a person from point a to point b
In programming a function is a named bit of code that does a specific task
You can define your own functions or you can use ones that the makers of processing created for you
The draw function is a good example
What is a variable?
you must tell the computer what kind of variable you are creating
you must tell the computer what to call the variable
you must tell the computer what the value of the variable is
What is a comment?
//
RGB?
How would you make purple?
0 to 255 range
alpha
if statements
very simply, if the statement in parentheses is true then the code in brackets runs. Otherwise the code in brackets after else runs. If there is no else statement, no code is run.
